# c-mediaplayer 

WIP

## Installation

```bash
# Clone the repository
git clone https://github.com/diegoperezm/c-mediaplayer.git

# Navigate to project directory
cd c-mediaplayer

# Create a build directory 
mkdir build

# Navigate to build directory 
cd build

# Configure the project with CMake 
cmake ..

# Build the project
make 
```

## Usage

```bash
# Run the app  
./release-cmediaplayer
```
